# Référentiel Naturo

Référentiel de naturopathie consultable en ligne : systèmes, pathologies, populations cibles, outils et techniques, recettes, thérapeutes recommandés.

- `index.html` : l'application
- `data.json` : toutes les fiches
- `img/` : schémas
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` : icône et affichage plein écran sur iPhone et iPad

Version de consultation : la modification des fiches se fait dans la version Claude.
Pour mettre à jour : remplacer `index.html`, `data.json` et le dossier `img/` par les nouvelles versions.
